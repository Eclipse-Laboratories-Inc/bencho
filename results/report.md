# Results

Generated by `scripts/summarize_results.py` from the Harbor jobs in `results/harbor-jobs`, which are not committed. `rewards.csv` has every reward key of every trial. `judged-reports/` has every graded audit report with the judge's match and rationale for each auditor finding.

Every agent ran in Harbor's `claude-code` harness with medium reasoning effort, 5 attempts per task. The report judge was `claude-opus-5-5`.

## Mean reward

For the fix formats the reward is the fraction of the audit's graded findings that a trial fixed. A finding counts only when its hidden tests pass and the project's existing test suite has no regressions. For the report format it is the fraction of the auditors' findings the report identified. Trials that errored score 0 and are counted in the errored row.

## Notes

- Harbor 0.24.0. Inkling ran in the same `claude-code` harness against Thinking Machines' Anthropic-compatible API.
- The judge model does not accept a fixed temperature, so rerunning the judge on the same report can credit a borderline finding differently.
- `fix-ticketed` names each defect, so it measures repair, not discovery. `fix` and `report` measure discovery.
